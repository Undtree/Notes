# 数据的表示与运算

## 数制与编码

### 进制及其转换

读者朋友们可能在接触这个专业之前就知道，在计算机系统内部所有信息都采用 **二进制** 进行编码。这主要是因为：

-   二进制只有两个状态，只需要使用就用两种稳定物理状态的物理器件即可表示每一位（高电平表示 1，低电平表示 0 等），硬件实现成本低。
-   二进制的两个状态恰好对应逻辑值的 true 和 false，为计算机实现逻辑运算和程序的条件判断提供了直接支持；
-   二进制下的运算规则极为简单（后续介绍），可通过基本的逻辑门电路高效实现各类算术与逻辑操作。

那么什么是“进制”？这是“进位计数制”的简称，也就是“逢x进一”。
